# Claude Code Remote Controlとは？スマホ・ブラウザからAIセッションを続ける方法を解説

「デスクで始めた作業を、外出先のスマホで続けられたら…」

そんな願いを、**Claude Code Remote Control**は実現します。自宅のPCで起動したClaudeのセッションを、スマートフォンや別のブラウザから引き継いで作業を続けられる機能です。

この記事では、Remote Controlとは何か、どんな場面で役立つのか、使い始め方をわかりやすく解説します。

---

## Remote Controlとは？

Remote Controlは、**ローカルPCで動くClaude Codeのセッションに、スマホや別デバイスからアクセスできる機能**です。

重要なのは、処理はすべて自分のマシン上で行われるという点です。クラウドに作業を移すのではなく、「スマホやブラウザをウィンドウとして使う」イメージです。

### できること

- **自分のローカル環境をそのまま使える**：ファイルシステム、MCPサーバー、ツール設定がすべてそのまま利用可能
- **複数デバイスで同時に操作できる**：ターミナル、ブラウザ、スマホのどこからでもメッセージを送れる
- **接続が切れても再接続できる**：ノートPCがスリープしてもネットワークが回復すれば自動で復帰

---

## どんな場面で便利か

### パターン①：デスクで始めた作業を外出先で続ける

午前中、自宅PCでコードのレビューを始めた。昼食後、外出しながらスマホで続きの確認だけしたい——そんな場面に最適です。

### パターン②：長時間タスクを離れた場所から監視する

テストの実行や大規模なファイル処理など、完了まで時間がかかる作業。PCの前に張り付かなくても、スマホから進捗を確認してClaude に次の指示を出せます。

### パターン③：複数デバイスで同じセッションを共有する

チームメンバーに作業状況を見せながら進める場合や、タブレットとPCを切り替えながら作業する場合にも活用できます。

---

## 使い始め方

### 必要な環境

- **Claude Code v2.1.51以降**（`claude --version`で確認）
- **claude.aiのサブスクリプション**（Pro / Max / Team / Enterprise）。APIキーは非対応
- 対応プラン：Pro、Max、Team、Enterprise（TeamとEnterpriseは管理者が有効化が必要）

### 3ステップで開始

**ステップ1：ログイン確認**

```bash
claude
/login
```

claude.aiアカウントでログインしていることを確認します。

**ステップ2：プロジェクトディレクトリに移動してセッションを開始**

```bash
cd /your/project
claude remote-control
```

ターミナルにセッションURLとQRコードが表示されます。

**ステップ3：スマホまたはブラウザで接続**

- 表示されたURLをブラウザで開く
- QRコードをスキャンしてClaudeアプリで開く
- `claude.ai/code` のセッション一覧から選択する

## 起動モードの違い

### サーバーモード（`claude remote-control`）

プロセスがターミナルで待機し、リモート接続を受け付け続けます。複数セッションの同時管理に向いています。

```bash
claude remote-control --name "マイプロジェクト"
```

### インタラクティブモード（`claude --remote-control`）

通常のClaude Codeセッションをリモートからも操作できるようにします。ターミナルとブラウザの両方から同じセッションに入力できます。

```bash
claude --remote-control "プロジェクト名"
```

### 既存セッションで有効化（`/remote-control`コマンド）

すでに会話中のセッションに対してリモートコントロールを後から追加できます。

```
/remote-control
```

---

## セキュリティの仕組み

Remote Controlは、ローカルマシンからのアウトバウンドHTTPS通信のみを使います。**PCへの受信ポートを開く必要はありません。**

すべての通信はAnthropicのAPIを経由し、TLSで暗号化されます。接続には短期間のみ有効な認証情報が使われ、用途ごとに独立して失効します。

---

## Claude Code on the webとの違い

|  | Remote Control | Claude Code on the web |
|---|---|---|
| 実行場所 | 自分のPCのローカル | Anthropicのクラウド |
| ファイルアクセス | ローカルファイルシステム | リポジトリをクラウドでクローン |
| MCPサーバー | 使用可能 | 使用可能（クラウド設定）|
| 向いている場面 | 進行中の作業を別デバイスで続ける | ローカル環境なしで新規タスクを開始 |

ローカル作業の延長として使うならRemote Control、環境を用意せず即タスクを始めるならClaude Code on the webという使い分けが基本です。

---

## モバイルプッシュ通知も設定できる

長時間かかるタスクが完了したとき、Claude がスマホにプッシュ通知を送る設定も可能です（Claude Code v2.1.110以降）。

```
/config → Push when Claude decides → 有効
```

テストが終わったら通知、入力が必要になったら通知——PCから離れていても安心して待てます。

## まとめ

| ポイント | 内容 |
|---|---|
| Remote Controlとは | ローカルPCのClaudeセッションをスマホ・ブラウザから操作する機能 |
| 処理場所 | 自分のPCのまま（クラウド移行なし）|
| 起動方法 | `claude remote-control` または `--remote-control` フラグ |
| 対応デバイス | ブラウザ全般・Claude iOS/Androidアプリ |
| セキュリティ | アウトバウンドHTTPSのみ・TLS暗号化 |

Remote Controlを使えば、「PCの前に縛られる」という制約から解放されます。デスクで始めた作業を、ソファでも電車の中でも続けられる——そんな柔軟な開発スタイルが手に入ります。
