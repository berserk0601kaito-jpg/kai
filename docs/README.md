# Forest Survival

このフォルダは GitHub Pages で公開されるゲームファイルです。

- ゲームソース: [`../game/index.html`](../game/index.html)
- 公開 URL: `https://<username>.github.io/<repo>/` (GitHub Pages 設定後)

## GitHub Pages 設定方法

1. リポジトリの Settings → Pages
2. Source: Deploy from a branch
3. Branch: このブランチ / `docs` フォルダを選択
4. Save
