# 星海の庭 〜 Stellar Garden 〜

星屑を落として融合させ、大宇宙を目指す幻想パズルゲーム。
依存ライブラリゼロ・単一HTMLファイルで動きます。

## 遊び方

`index.html` をブラウザで開くだけ。インストール・ビルド不要。

```
# ローカルで開く場合
open stellar-garden/index.html        # mac
start stellar-garden\index.html       # Windows
```

スマホでも遊べます（タッチ操作対応）。

## ルール

- 画面をタップ / クリックすると、持っている天体がその位置に落ちます
- **同じ天体同士が触れると融合して、ひとつ上の天体に進化します**
- 進化チェーン（11段階）:

  星屑 › 流星 › 彗星 › 月 › 惑星 › 恒星 › 超新星 › 星雲 › 銀河 › 銀河団 › **大宇宙**

- 大宇宙同士を融合させると **ビッグバン** が起きて大量ボーナス
- 融合が1.1秒以内に連鎖すると **コンボ** でスコア倍率アップ
- 上の点線より上に積み上がったままになるとゲームオーバー

## 操作

| 操作 | マウス / タッチ | キーボード |
|---|---|---|
| 狙う | ポインタ移動 / ドラッグ | ← → |
| 落とす | クリック / 指を離す | Space / ↓ |
| ミュート | 右上の🔊ボタン | M |

## 技術メモ

- Canvas 2D + 自作の円物理エンジン（重力・衝突・質量比インパルス解決、4サブステップ）
- BGM・効果音はすべて WebAudio によるリアルタイム合成（音源ファイルなし）
- ベストスコアとミュート設定は localStorage に保存
- 星空・星雲・流れ星の背景は手続き生成
