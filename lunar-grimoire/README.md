# 月詠の魔導書 〜 Lunar Grimoire 〜

月夜の森で押し寄せる夜の精霊から10分間生き延びる、
**サバイバー系ローグライト × スペル合成発見**ゲーム。
依存ライブラリゼロ・単一HTMLファイル。

## 遊び方

`index.html` をブラウザで開くだけ。スマホ対応（タッチ操作）。

- 移動：画面ドラッグ（バーチャルスティック）/ WASD・矢印キー
- **攻撃はすべて自動**。動き回って敵を捌き、経験値を集めるのが仕事
- レベルアップで3枚のカードから1枚選ぶ

## コアシステム：元素を「紡ぐ」

カードで **5つの元素（炎・氷・月・雷・風）** を手に取れる。
**元素を2つ集めると自動で紡がれてスペルになる。**

組み合わせは全15種。どの組み合わせが何になるかは、
実際に紡いで「発見」するまで ？？？ のまま——
発見したスペルは**魔導書（図鑑）に恒久記録**される。

例：
- 月＋月 = ルナブラスト（追尾弾）
- 炎＋雷 = 雷火（貫通斉射）
- 氷＋氷 = ？？？（自分で見つけよう）

同じ組み合わせをもう一度紡ぐとスペルがレベルアップ（最大Lv5）。
スペルは最大5枠。何を紡ぐかでビルドが毎回変わる。

## 進行

- 約2.5分ごとに**ボス**が出現（全4体）。エリートは宝箱を落とす
- 10分生存 or 最終ボス「蝕月オロチ」撃破で**夜明け（クリア）**
- 倒れても**月の欠片**を持ち帰り、「月の祭壇」で恒久強化
  （最大HP・威力・移動速度・吸引・幸運の5系統 × 5段階）

## 技術メモ

- Canvas 2D、カメラ追従の無限フィールド（木・光るキノコ・蛍はハッシュ手続き生成）
- 8種のスペル挙動アーキタイプ（弾・周回・連鎖・衝撃波・落雷・嵐雲・ブーメラン・オーラ）＋状態異常（火傷・鈍足・凍結）
- BGM・効果音は WebAudio リアルタイム合成（ボス戦でテンポが変わる）
- メタ進行・図鑑・ベスト記録は localStorage 保存
